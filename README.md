# Inside Linglong One

An interactive 3D site about Linglong One (玲龙一号), China's small modular reactor at Changjiang, Hainan.

Zoom from the whole of China down to the plant, then look inside the reactor building and turbine hall, step through how the energy flows, and watch the build history.

Everything is in one file, `index.html`: the 3D library (three.js r128, MIT licence), the satellite images and the code. It needs no server and no outside downloads apart from the fonts.
